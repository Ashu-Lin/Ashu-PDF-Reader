# Ashu PDF Reader 项目书

## 1. 一句话定位

一个 Windows 优先、启动即选文件、阅读时几乎没有任何界面干扰的极简 PDF 阅读器。

## 2. 目标

- 打开应用就能选择 PDF。
- 选中后只看到 PDF 内容。
- 菜单、按钮、功能入口全部通过快捷键或悬停唤起。
- 阅读窗口可自由调整大小，PDF 自动适配宽度。
- 项目文档、版本记录和任务清单足够清晰，方便 AI 和开源协作者接手。

## 3. 第一版范围

### 必做

- 启动即调用 Windows 原生文件选择器。
- 用户取消选择时退出应用。
- 单窗口模式。
- PDF 渲染、滚动、翻页。
- 放大、缩小、适配宽度。
- 窗口宽高变化时重新适配宽度。
- 无边框窗口。
- 顶部悬停控制条。
- Alt + 拖动移动窗口。
- 边缘和四角调整窗口大小。
- 核心快捷键。

### 暂不做

- 多标签。
- 注释、高亮、签名、表单。
- OCR。
- 云同步、账号系统。
- PDF 创建和格式转换。
- 完整适配 macOS / Linux。

## 4. 用户流程

1. 双击应用。
2. 系统文件选择器出现。
3. 如果取消，应用退出。
4. 如果选择 PDF，窗口进入阅读模式。
5. 默认只显示 PDF 页面。
6. 鼠标移到顶部，出现极薄控制条。
7. 使用快捷键完成打开、搜索、目录、缩放等操作。

## 5. 交互规范

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 打开文件 | Ctrl+O | 再次打开 PDF |
| 搜索 | Ctrl+F | 第一版可预留 |
| 目录 | Ctrl+B | 第一版可预留 |
| 放大 | Ctrl+= | 按比例放大 |
| 缩小 | Ctrl+- | 按比例缩小 |
| 适配宽度 | Ctrl+0 | 默认模式 |
| 命令面板 | Ctrl+Shift+P 或 F1 | 汇总所有功能 |
| 关闭浮层 | Esc | 命令面板、目录、搜索 |
| 移动窗口 | Alt + 拖动 | 任意位置拖动 |
| 调整大小 | 边缘 / 四角拖动 | 保持普通窗口直觉 |

## 6. UI 原则

- 文档是主角，应用壳层退后。
- 阅读区默认无工具栏。
- 顶部控制条只在鼠标靠近顶部时出现。
- 使用深色桌面衬托暖白 PDF 纸张。
- 只保留一个强调色，用于焦点、状态和细微反馈。
- 动画只服务于反馈，不做装饰。

## 7. 技术方案

- 桌面框架：Tauri 2
- 前端：Vue 3 + TypeScript + Vite
- PDF 渲染：pdfjs-dist
- 包管理：pnpm
- 文件选择：Tauri dialog 插件
- 窗口控制：Tauri window API
- 目标平台：Windows 优先，保留跨平台扩展空间

## 9. 验收标准

- 应用启动后立即出现 PDF 文件选择器。
- 取消选择后应用退出。
- 选择 PDF 后同一窗口进入阅读模式。
- 默认界面不显示工具栏和菜单。
- PDF 自动适配窗口宽度。
- 调整窗口宽高后 PDF 重新适配。
- Alt + 拖动能移动窗口。
- 边缘和四角能调整窗口大小。
- 快捷键可打开核心功能。
- Windows 构建可正常安装和启动。
