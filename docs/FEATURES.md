# 功能说明

## 已实现

| 功能 | 状态 | 说明 |
|---|---|---|
| 启动选择 PDF | 已实现 | 启动后立即打开 Windows 原生文件选择器 |
| 取消选择退出 | 已实现 | 取消文件选择后关闭窗口 |
| 单窗口阅读 | 已实现 | 选择后同一窗口进入阅读 |
| PDF 渲染 | 已实现 | 使用 PDF.js 将页面渲染到 Canvas |
| 适配宽度 | 已实现 | 默认按窗口宽度适配 |
| 窗口变化重新适配 | 已实现 | ResizeObserver 监听阅读区变化 |
| 放大缩小 | 已实现 | Ctrl+=、Ctrl+-、Ctrl+滚轮 |
| 打开另一个文件 | 已实现 | `Ctrl+O` |
| 命令面板 | 已实现 | `F1` 或 `Ctrl+Shift+P` |
| 无边框窗口 | 已实现 | 不显示系统标题栏 |
| 顶部悬停控制条 | 已实现 | 鼠标靠近顶部时出现 |
| Alt 拖动窗口 | 已实现 | 任意位置拖动 |
| 边缘缩放 | 已实现 | 四边和四角热区 |
| Windows 安装包 | 已实现 | 已生成 MSI 和 NSIS 调试安装包 |

## 验收标准

- 应用启动后立即出现 PDF 文件选择器。
- 取消选择后应用退出。
- 选择 PDF 后同一窗口进入阅读。
- 默认不显示工具栏和菜单。
- PDF 适配窗口宽度。
- 调整窗口大小后 PDF 重新适配。
- `Alt + 拖动` 能移动窗口。
- 边缘和四角能调整窗口大小。
- Windows 构建可安装和启动。
